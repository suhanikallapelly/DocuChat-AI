# 📄 RAG PDF Chatbot

🤖 **Chat with your PDFs using AI!**

A simple **RAG-based PDF Chatbot** built with **Streamlit, Ollama, Sentence Transformers, and ChromaDB**. Upload a PDF, ask questions, and get relevant answers from your document.

### ✨ Features

* 📂 Upload PDF files
* 💬 Ask questions naturally
* 🔍 RAG-powered document search
* 🧠 Local AI with Ollama
* ⚡ Simple Streamlit interface
